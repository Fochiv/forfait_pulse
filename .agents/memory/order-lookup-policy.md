---
name: Phone-only order lookup
description: The user's privacy and verification choice for Forfait Pulse order history.
---

Forfait Pulse order lookup uses only a customer's phone number. The user explicitly chose this option over phone plus SMS verification after being told that anyone who knows the number could view the associated orders.

**Why:** The user prefers simple phone-only access and accepted the privacy tradeoff.

**How to apply:** Keep the phone number as the only required identifier for customer order lookup, limit exposed order details, and retain reasonable abuse controls. Ask before adding SMS or another verification requirement.
